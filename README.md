# 杀戮尖塔 · 简明版 (Slay the Spire Lite)

纯前端（HTML5 + Vanilla CSS + ES Modules）实现的简化版《杀戮尖塔》肉鸽卡牌策略游戏，零第三方运行时依赖，内置确定性随机数种子（Mulberry32）、实时 Web Audio 合成音效、响应式手机端触控适配与完整自动化测试套件。

在线游玩：<https://lishiyi.github.io/card-game/>

## 核心玩法与特性

- **3–4 列平面无交叉分支地图与双幕攀登**：第 1–5 层零精英平滑过渡、第 9 层必遇**远古宝箱室**、严禁连续精英/营地/商店连边；击败第一幕随机首领（【尖塔守护者】、【六火亡魂】、【史莱姆老大】半血分裂）后进入**首领遗物三选一祭坛**，可选择凯旋结算或继续踏入**第二幕 · 钢铁城邦**（迎战【百夫长与秘术师】、【刺击魔典】、【青铜自动机】、【收藏家】等强敌）。
- **深度流派卡池（共 46 张卡牌）**：
  - 完整支持**力量重击流**、**消耗流**（【无惧疼痛】【黑暗之拥】【腐化】【重振精神】【恶魔之焰】）、**格挡壁垒流**（【壁垒】【巩固】【火焰屏障】【全身撞击】）与**吸血续航**（【死神收割】）。
  - 支持 `固有`、`保留`、`虚无`、`消耗` 关键词，以及状态牌（【粘液】【晕眩】【灼伤】）与诅咒牌（【笨拙】【疑虑】【悔恨】）。
- **22 件分档遗物、10 种药水与 10 大未知事件**：
  - 遗物划分为初始 / 普通 / 罕见 / 稀有 / 首领五档；药水扩充至 10 种；内置 10 个高抉择随机事件。
- **战斗动画反馈、Web Audio 合成音效与设置面板**：
  - 内置 9 组 CSS `@keyframes` 动态反馈（出牌残影飞行、交错发牌入场、受击震动闪白、伤害/回血/叠盾飘字、护盾击碎光环与破盾提示）。
  - 零外部音频资源 Web Audio 实时合成音效，设置面板支持**一键静音、0–100% 音量滑块、标准 1x / 快速 2x / 关闭动画三档速度**与飘字开关。
- **敌人下回合行动预判、关键词百科与种子战绩系统**：
  - 实时模拟状态衰减、邪教徒仪式成长与首领阶段循环，在意图下方直接展示**下回合可能行动及概率分布**。
  - 内置可搜索/分类筛选的**尖塔百科（关键词与状态词典）**与**三步新手引导**。
  - 自动持久化最近 30 场**历史战绩编年史**，支持复制种子代码（如 `S-16`）与好友**指定种子同图竞速**。
- **深度手机端适配**：
  - 多断点响应式布局（`<= 980px`、`<= 768px`、`<= 520px` 及触屏指针媒体查询），手牌区支持横向顺滑触控滚动，遗物/药水/状态/意图全面支持**轻触点按查看详情气泡**。

## 本地运行与工程化工具

```bash
# 运行全部 37 项测试（单元测试、150 局全流程不变量模糊测试、打包校验与 5 组无头浏览器桌面/手机端 E2E 测试）
npm test

# 从 src/main.js 自动解析依赖图并拓扑打包单文件离线 HTML（输出至 dist/slay_the_spire_lite.html）
npm run build:standalone

# 启动本地静态服务器（默认 http://localhost:4173）
npm start
```

## 目录结构

- `index.html` — 语义化入口页面
- `styles/main.css` — 纯原生 CSS 设计系统、`@keyframes` 动画与桌面/手机多断点响应式样式
- `src/data/` — 冻结只读的数据定义（卡牌、敌人 AI 状态机与下回合行动预测、遗物药水、地图与随机事件）
- `src/engine/` — 纯逻辑核心引擎（确定性 RNG 与种子编解码、伤害/格挡数值计算、回合战斗引擎、全局攀登状态机、生涯与战绩持久化）
- `src/ui/` — 模块化前端架构（主控制器 `app.js`、合成音效 `audio.js`、战斗特效层 `fx.js`、设置 `settings.js`、词典 `glossary.js`、SVG 图标库 `icons.js`）
- `src/ui/screens/` — 按界面拆分的渲染模块（顶部栏 `hud.js`、路线地图 `map.js`、战斗舞台 `combat.js`、事件 `event.js`、宝箱/营地/商店/结算 `outpost.js`、弹窗合集 `modals.js`）
- `scripts/build-standalone.mjs` — 基于 ES Module 依赖图自动拓扑排序的单文件 HTML 构建器
- `.github/workflows/ci.yml` — GitHub Actions 自动化测试与 GitHub Pages 持续部署流水线
- `tests/` — 单元测试、对抗性审查（`critic.grill`）模糊测试与真实 Chromium 桌面/移动端 E2E 测试
