# 杀戮尖塔 · 简明版 (Slay the Spire Lite)

纯前端（HTML5 + Vanilla CSS + ES Modules）实现的简化版《杀戮尖塔》肉鸽卡牌策略游戏，零第三方运行时依赖，内置确定性随机数种子（Mulberry32）与完整自动化测试套件。

## 核心玩法与特性

- **3–4 列平面无交叉分支地图与双幕攀登**：第 1–5 层零精英平滑过渡、第 9 层必遇**远古宝箱室**、严禁连续精英/营地/商店连边；击败第一幕随机首领（【尖塔守护者】、【六火亡魂】、【史莱姆老大】半血分裂）后进入**首领遗物三选一祭坛**，可选择凯旋结算或继续踏入**第二幕 · 钢铁城邦**（迎战【百夫长与秘术师】、【刺击魔典】、【青铜自动机】、【收藏家】等强敌）。
- **深度流派卡池（共 46 张卡牌）**：
  - 完整支持**力量重击流**、**消耗流**（【无惧疼痛】【黑暗之拥】【腐化】【重振精神】【恶魔之焰】）、**格挡壁垒流**（【壁垒】【巩固】【火焰屏障】【全身撞击】）与**吸血续航**（【死神收割】）。
  - 支持 `固有`、`保留`、`虚无`、`消耗` 关键词，以及状态牌（【粘液】【晕眩】【灼伤】）与诅咒牌（【笨拙】【疑虑】【悔恨】）。
- **22 件分档遗物、10 种药水与 10 大未知事件**：
  - 遗物划分为初始 / 普通 / 罕见 / 稀有 / 首领五档（含【纸蛙】【鸟居】【钨合金棍】【卡戎之灰】【天鹅绒项圈】【诅咒钥匙】【神圣树皮】等）；药水扩充至 10 种。
  - 10 个高抉择随机事件（含【活体石墙】删牌/变化/升级、【静谧藏书阁】三选一、【黄金神像】、【诅咒魔典】、【怪诞炼金师】、【荧光蘑菇窟】等）。
- **精细化数值曲线与局外成长（进阶 0–5 & 历练解锁）**：
  - 战斗金币与奖励卡牌升级率随层数/幕数平滑递增；商店删牌阶梯涨价（`75 → 100 → 125...`）；**稀有牌动态保底**（每次未出金累加 `+2%` 稀有率，出金重置）。
  - 跨局持久化**生涯历练 XP**（3 阶核心卡牌/遗物觉醒图鉴）与 **进阶 0–5** 累计挑战难度（并提供测试用一键全解锁开关）。

## 本地运行与测试

```bash
# 运行全部 32 项单元测试、150 局全流程不变量模糊测试与无头 Chromium E2E 测试
npm test

# 构建单文件离线可玩 HTML
npm run build:standalone

# 启动本地静态服务器（默认 http://localhost:4173）
npm start
```

## 目录结构

- `index.html` — 语义化入口页面
- `styles/main.css` — 纯原生 CSS 设计系统与卡牌交互样式
- `src/data/` — 冻结只读的数据定义（卡牌、敌人与 AI 状态机、遗物药水、地图与随机事件）
- `src/engine/` — 纯逻辑核心引擎（确定性 RNG、伤害/格挡/意图数值计算、回合战斗引擎、全局攀登状态机）
- `src/ui/` — 手绘内联 SVG 角色插画与前端视图控制器
- `tests/` — 单元测试、对抗性审查（`critic.grill`）测试与真实浏览器 E2E 测试
