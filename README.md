# 杀戮尖塔 · 简明版 (Slay the Spire Lite)

纯前端（HTML5 + Vanilla CSS + ES Modules）实现的简化版《杀戮尖塔》肉鸽卡牌策略游戏，零第三方运行时依赖，内置确定性随机数种子（Mulberry32）与完整自动化测试套件。

## 核心玩法与特性

- **16 层分支攀登地图与专属节点图标**：包含普通战斗（普通小怪图标）、精英强敌（双角恶魔巨怪图标）、篝火营地、神秘商人、未知事件（【闪耀圣光】【遗落锻炉】等升级事件实时展示具体被强化的卡牌）与第 16 层首领战，带 SVG 路线连线预览。
- **核心卡牌战斗循环**：
  - 能量系统（每回合重置）、抽牌堆 / 手牌（上限 10 张）/ 弃牌堆（自动洗回）/ 消耗堆（Exhaust & 虚无 Ethereal）/ 能力牌（Power）。
  - 20+ 张经典铁甲战士卡牌，区分**攻击（利剑图标）/ 技能（护盾图标）/ 能力（雷霆图标）**标识，并按**基础 / 普通（银灰）/ 罕见（天蓝）/ 稀有（耀金）**区分专属配色与徽章，全部支持 `+` 升级（绿字预览完整体现减费与数值强化）及实时伤害/格挡动态预览。
- **丰富怪物池与精确状态结算**：
  - 力量（Strength）、敏捷（Dexterity）、易伤（Vulnerable +50%）、虚弱（Weak -25%）、脆弱（Frail -25%）、金属化、恶魔形态、禁抽。
  - 分阶段遭遇池与特色机制：邪教徒【仪式】、颚虫、红绿虱虫【蜷缩】、酸液/尖刺史莱姆、真菌兽【孢子云】、蓝衣奴隶贩、尖塔劫匪、狂怒地精【愤怒】，精英地精大块头【激怒】、双子远古哨卫【晕眩干扰】、精英乐加维林【金属化 / 灵魂虹吸】，以及首领尖塔守护者【形态转换 / 锋利外壳】。
- **遗物、药水、战利品防漏领提示与悬停详情**：7 种经典遗物与 4 种战斗药水；战利品结算点击「继续前进」时自动检测未领取的金币或遗物并弹窗提示（药水与卡牌可自由跳过无打扰）；鼠标悬停至遗物、药水、自身与怪物的所有 Buff / Debuff 及敌方意图时即时显示详情提示；支持战斗内一键「重启本场战斗」、自动存档（`localStorage`）与快捷键（`1-9` 出牌、`E` 结束回合、`D` 查看牌组、`Esc` 取消选择/关闭弹窗）。

## 本地运行与测试

```bash
# 运行单元测试、对抗性边界/不变量模糊测试与无头 Chromium E2E 测试
npm test

# 启动本地静态服务器（默认 http://localhost:4173）
npm start
```

## 目录结构

- `index.html` — 语义化入口页面
- `styles/main.css` — 纯原生 CSS 设计系统与卡牌交互样式
- `src/data/` — 冻结只读的数据定义（卡牌、敌人与 AI 状态机、遗物药水、地图与随机事件）
- `src/engine/` — 纯逻辑核心引擎（确定性 RNG、伤害/格挡/意图数值计算、回合战斗引擎、全局攀登状态机）
- `src/ui/` — 手绘内联 SVG 角色插画与前端视图控制器
- `tests/` — 单元测试、对抗性审查（`critic.grill`）测试与真实浏览器 E2E 测试
