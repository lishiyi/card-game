# 杀戮尖塔 · 简明版 (Slay the Spire Lite)

纯前端（HTML5 + Vanilla CSS + ES Modules）实现的《杀戮尖塔》风格肉鸽卡牌策略游戏，零第三方运行时依赖，内置确定性随机数种子（Mulberry32）、实时 Web Audio 合成音效、深度桌面/手机端触控适配与完整自动化测试套件。

在线游玩：<https://lishiyi.github.io/card-game/>

## 核心玩法与特性

- **双角色体系与独立生涯进度**：
  - **铁甲战士（The Ironclad）**（55 张专属牌）：完整覆盖力量重击流、消耗流（【无惧疼痛】【黑暗之拥】【腐化】【恶魔之焰】【重振精神】）、格挡壁垒流（【壁垒】【巩固】【火焰屏障】【全身撞击】）与自残续航体系。
  - **静默猎手（The Silent）**（55 张专属牌）：完整覆盖剧毒爆发流（【催化剂】【尸爆术】【毒性烟雾】）、小刀连击流（【刀刃之舞】【精准】【余像】【手里剑/苦无】）与弃牌过牌流（【策略家】【本能反应】【铁甲绷带】【丁夏】【内脏切除】）。
  - 另含 11 张跨职业无色牌（含商店专属无色货架 10 张 + 事件专属【幽灵化】）及状态/诅咒牌，合计 **130 张卡牌**。
  - 支持**按角色独立进阶解锁（A0–A10）与角色生涯档案**，记录各角色最高进阶、胜率、历史最高层与最高分。
- **完整三幕攀登、40 种敌人与 9 大首领**：
  - 3–4 列平面无交叉分支地图、第 0 层**鲸鱼赐福（Neow）**、第 1–5 层零精英平滑开局、第 9 层分级远古宝箱室、严禁连续精英/营地/商店连边。
  - **第一幕 · 塔底废墟**（首领：【尖塔守护者】【六火亡魂】【史莱姆老大】）、**第二幕 · 钢铁城邦**（新增【异鸟（飞行）】【球形守卫（壁垒）】【蛇花（可塑护甲）】【地精首领】精英，首领：【青铜自动机】【收藏家】【第一勇士】）、**第三幕 · 深渊圣殿**（【尖刺机】【自爆体】【斥力体】【巨型头颅】【死灵法师】【唤蛇师】，首领：【时光吞噬者】【觉醒者】【八体与甜圈】；进阶 10 解锁终幕双首领连战）。
- **55 件分档遗物、14 种药水与 19 大分幕事件**：
  - 遗物按初始（2）/ 普通（12）/ 罕见（11）/ 稀有（11）/ 商店专属（5）/ 事件专属（4，含【黄金神像】→【染血神像】升华）/ 首领（10）严格分池；药水共 14 种（10 通用 + 2 战士专属 + 2 猎手专属）。
  - **19 个按幕次过滤（`minAct`/`maxAct`）的未知事件**，涵盖废料软泥、翼龙石像、幽灵议会、遗忘祭坛、炼体改造师、心花怒放、记忆晶石、曲折回廊等经典高抉择事件，并在进阶 8 下动态强化风险与收益权衡。
- **统一战斗交互选牌引擎与战术预判**：
  - 支持**交互式弃牌、自选消耗（如【破釜沉舟+】）、手牌自选升级（如【武装】）与预见（Scry）弹窗**。
  - 实时计算斩杀/破盾预判（完整模拟飞行减伤、可塑护甲递增、蜷缩、毒斩杀、多段/X 费）、卡牌协同提示、敌人**下回合行动概率预判**及战斗重开快照。
- **进阶 0–10、每日挑战与战报分享**：
  - 内置 10 阶进阶梯度规则、每日同图同词条挑战（10 种规则词条、评分评级与历史榜单）、好友种子/挑战链接（`?seed=` / `?char=` / `?daily=`）与一键复制战报。
- **动画音效、百科与深度手机端单手适配**：
  - 内置 9 组 CSS `@keyframes` 动画与零素材 Web Audio 实时合成音效，支持三档动画速度与音量/静音调节；内置可搜索关键词百科与三步新手引导。
  - 针对手机竖屏（`<= 768px`）深度优化：弹窗防穿透滚动锁与顶部首行零遮挡、药水独立一行、右手单手友好的右侧「结束回合」与「继续前进」布局、可折叠战报、轻触气泡与二段点选/上滑拖拽出牌。

## 本地运行与工程化工具

```bash
# 运行全部 64 项自动化测试（单元测试、150 局全流程不变量模糊测试、打包校验与 13 组无头 Chromium 桌面/手机端 E2E 测试）
npm test

# 从 src/main.js 自动解析依赖图并拓扑打包单文件离线 HTML（输出至 dist/slay_the_spire_lite.html）
npm run build:standalone

# 启动本地静态服务器（默认 http://localhost:4173）
npm start
```

## 目录结构

- `index.html` — 语义化入口页面
- `styles/main.css` — 纯原生 CSS 设计系统、`@keyframes` 动画与桌面/手机多断点响应式样式
- `src/data/` — 冻结只读的数据定义（角色、130 张卡牌、40 种敌人 AI 状态机与下回合行动预测、55 件遗物与 14 种药水、地图与 19 个分幕事件）
- `src/engine/` — 纯逻辑核心引擎（确定性 RNG 与种子/挑战链接编解码、攻防数学、回合战斗与选牌/预见引擎、战术预判、每日挑战、全局攀登状态机、分角色生涯与战绩持久化）
- `src/ui/` — 模块化前端架构（主控制器 `app.js`、战斗交互与拖拽 `combat_interact.js`、合成音效 `audio.js`、特效层 `fx.js`、设置 `settings.js`、词典 `glossary.js`、SVG 图标库 `icons.js`）
- `src/ui/screens/` — 按界面拆分的渲染模块（角色选择 `character_select.js`、顶部栏 `hud.js`、路线地图 `map.js`、战斗舞台 `combat.js`、事件 `event.js`、宝箱/营地/商店/结算 `outpost.js`、弹窗与预见层 `modals.js`）
- `scripts/build-standalone.mjs` — 基于 ES Module 依赖图自动拓扑排序的单文件 HTML 构建器
- `.github/workflows/ci.yml` — GitHub Actions 自动化测试与 GitHub Pages 持续部署流水线
- `tests/` — 单元测试、对抗性审查（`critic.grill`）150 局模糊测试与真实 Chromium 桌面/移动端 E2E 测试
