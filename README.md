# 杀戮尖塔 · 简明版 (Slay the Spire Lite)

纯前端（HTML5 + Vanilla CSS + ES Modules）实现的简化版《杀戮尖塔》肉鸽卡牌策略游戏，零第三方运行时依赖，内置确定性随机数种子（Mulberry32）与完整自动化测试套件。

## 核心玩法与特性

- **7 层分支攀登地图**：包含普通战斗、精英战、篝火营地（休息回血 / 铁砧锻造升级卡牌）、神秘商人（购卡、遗物、药水、永久移除卡牌）、未知事件与第 7 层首领战，带 SVG 路线连线预览。
- **核心卡牌战斗循环**：
  - 能量系统（每回合重置）、抽牌堆 / 手牌（上限 10 张）/ 弃牌堆（自动洗回）/ 消耗堆（Exhaust & 虚无 Ethereal）/ 能力牌（Power）。
  - 20+ 张经典铁甲战士卡牌（打击、防御、痛击、剑柄打击、耸肩无视、双重打击、顺势斩、全身撞击、重刃、旋风斩 X 费、盛怒、战斗专注、放血、祭品、岿然不动、恶魔形态、重锤等），按**基础 / 普通（银灰）/ 罕见（天蓝）/ 稀有（耀金）**区分专属配色与徽章，全部支持 `+` 升级（绿字预览完整体现减费与数值强化，减费后费用球高亮为翡翠绿）及实时伤害/格挡动态预览。
- **精确状态与被动结算**：
  - 力量（Strength）、敏捷（Dexterity）、易伤（Vulnerable +50%）、虚弱（Weak -25%）、脆弱（Frail -25%）、金属化、恶魔形态、禁抽。
  - 敌人意图实时计算与特色机制：邪教徒【仪式】、虱虫【蜷缩】、地精大块头【激怒】、远古哨卫【晕眩干扰】、首领尖塔守护者【形态转换 / 锋利外壳】。
- **遗物、药水与悬停详情提示**：7 种经典遗物与 4 种战斗药水；鼠标悬停至遗物、药水（含非战斗禁用状态）、自身与怪物的所有正面/负面状态（Buff / Debuff）及敌方意图时，即时弹出浮动效果详情提示；支持战斗内一键「重启本场战斗」、自动存档（`localStorage`）与快捷键（`1-9` 出牌、`E` 结束回合、`D` 查看牌组、`Esc` 取消选择/关闭弹窗）。

## 本地运行与测试

```bash
# 运行单元测试、对抗性边界/不变量模糊测试与无头 Chromium E2E 测试
npm test

# 启动本地静态服务器（默认 http://localhost:4173）
npm start
```

## 目录结构

- `index.html` — 语义化入口页面
- `styles/main.css` — 纯原生 CSS 设计系统与卡牌交互样式
- `src/data/` — 冻结只读的数据定义（卡牌、敌人与 AI 状态机、遗物药水、地图与随机事件）
- `src/engine/` — 纯逻辑核心引擎（确定性 RNG、伤害/格挡/意图数值计算、回合战斗引擎、全局攀登状态机）
- `src/ui/` — 手绘内联 SVG 角色插画与前端视图控制器
- `tests/` — 单元测试、对抗性审查（`critic.grill`）测试与真实浏览器 E2E 测试
